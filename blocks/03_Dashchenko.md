**Головна теза:** 
Для злому автономного ШІ не обов'язково атакувати систему безпосередньо чи викрадати паролі. Достатньо непомітно звичайний вебсайт, лист або документ, який нейромережа прочитає під час виконання завдання. Ця фундаментальна вада стала головною нерозв'язаною загрозою 2025–2026 років

**Що таке Indirect Prompt Injection?**
Indirect Prompt Injection (непряма ін'єкція промпта) - це кібератака, при якій зловмисник маскує шкідливі команди для ШІ всередині звичайних файлів, вебсторінок або електронних листів. Коли AI-агент - штучний інтелект якому дали доступ до інструментів, наприклад: браузера чи терміналу чи баз даних, аналізує цей файл, він не відрізняє системні команди від звичайного тексту і сприймає прихований напис як новий наказ номер 1. У 2025 році провідний стандарт безпеки OWASP визнав це вразливістю №1 для ШІ (під кодом LLM01)

**Як це працює на реальному прикладі:**
Уявіть, що ви просите свого корпоративного ШІ-асистента знайти інформацію в листах. Агент сканує пошту і натрапляє на лист від хакера. Навіть якщо ви ніколи не відкривали цей лист, агент зчитує схований напис і слухняно надсилає хакеру ваші файли це називається атакою *zero-click* — злам без жодних дій з боку користувача. Саме так працювала реальна атака EchoLeak на систему Microsoft 365 Copilot. 

Інший свіжий кейс - злам агента на GitHub. Хакер сховав текст у публічному репозиторії. Коли чужий агент розробника її прочитав, то через отриману команду невидимо викрав код із приватних проєктів свого власника.

**Чому це критична загроза для AI-агентів?**
Для звичайного чат-бота така атака не є катастрофою, адже він лише генерує текст на екрані. Однак сучасні агенти мають розширені права та використовують генерацію тексту, що доповнюється автоматичним пошуком по зовнішніх базах даних. Оскільки нейромережа не розуміє різниці між вашим завданням і чужою командою з інтернету, отруєний документ дозволяє хакеру керувати діями агента: надсилати фішингові листи чи видаляти бази даних від імені користувача. Класичні антивіруси тут безсилі, адже ШІ сам завантажує цей текст для аналізу.
